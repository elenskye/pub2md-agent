          How to Use
          • Upload a PDF → one bilingual Markdown file per article (English paragraph, then its Chinese translation).
          • Upload a Markdown file → one Chinese-only Markdown file, with the original structure kept exactly as it was.
          • Source language: English or Traditional Chinese only. Traditional Chinese is converted to Simplified, not re-translated.
          • Pick a translation style for the tone, and any number of glossary domains to force consistent terminology. Select no domain to translate without a glossary.
          • Translate runs one pass. Refined Translation adds a second review-and-rewrite pass: better wording, roughly double the time and cost.
